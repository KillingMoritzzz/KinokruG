# Кинокружок: сайт оценки фильмов для сервера Discord

Участники входят через Discord. Сайт проверяет, что человек состоит на вашем сервере, и привязывает оценки к его аккаунту (один человек: один голос на фильм). Рейтинг IMDb подтягивается автоматически через OMDb API.

## Что понадобится (всё бесплатно)
1. Аккаунт на GitHub, чтобы загрузить код.
2. Аккаунт на Render (render.com): там будет работать сайт.
3. Аккаунт на Neon (neon.tech): там будет храниться база оценок.

## Шаг 1. Приложение Discord
1. Откройте https://discord.com/developers/applications → New Application.
2. Слева OAuth2: скопируйте **Client ID** и нажмите Reset Secret, чтобы получить **Client Secret**.
3. В разделе Redirects добавьте адрес `https://АДРЕС-ВАШЕГО-САЙТА/auth/callback`. Для проверки на своём компьютере добавьте ещё `http://localhost:3000/auth/callback`.
4. В Discord откройте Настройки → Расширенные → включите «Режим разработчика». Правый клик по иконке сервера → «Копировать ID сервера». Правый клик по своему имени → «Копировать ID пользователя» (он нужен для ADMIN_IDS).

## Шаг 2. Ключ OMDb
Получите бесплатный ключ на https://www.omdbapi.com/apikey.aspx (до 1000 запросов в день).

## Шаг 3. База данных
В Neon создайте проект и скопируйте строку подключения (Connection string, начинается с `postgresql://`). Таблицы создаются автоматически при первом запуске.

## Шаг 4. Запуск на Render
1. Загрузите папку проекта в новый репозиторий на GitHub (файл `.env` не загружайте).
2. На Render: New → Web Service → выберите репозиторий.
3. Build Command: `npm install`. Start Command: `npm start`.
4. В Environment добавьте переменные из `.env.example`. В `BASE_URL` впишите адрес, который Render выдал сайту (например `https://kinokruzhok.onrender.com`). Этот же адрес с `/auth/callback` должен быть в Redirects приложения Discord.
5. После запуска откройте сайт, войдите через Discord (ваш ID должен быть в `ADMIN_IDS`) и добавьте фильмы по IMDb ID. ID виден в ссылке на фильм: imdb.com/title/**tt0111161**/. Можно вставить ссылку целиком.

Бесплатный тариф Render «засыпает» после 15 минут без посетителей, поэтому первое открытие может занять около минуты.

## Проверка на своём компьютере
Нужен Node.js 20 или новее. Скопируйте `.env.example` в `.env`, заполните и выполните:
```
npm install
npm run dev
```
Сайт откроется на http://localhost:3000.

## Настройка названия
Название сайта задаётся в `public/index.html` в строке `const SITE = ...`.
